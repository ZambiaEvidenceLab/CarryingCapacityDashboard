# Equal weighting within and across dimensions

Per the OECD Handbook on Constructing Composite Indicators (Step 6), we chose equal weighting (EW) over statistical (PCA/FA) or expert-elicited (BAP/AHP) weights, applied at two levels: every Indicator within a Dimension is weighted equally, and Supply/Access are weighted 50/50 within a Sector (already specified in the original methodology). This two-level structure deliberately avoids the "unbalanced structure" the handbook warns about, where equal-weighting raw indicators directly would let a dimension with more indicators dominate the sector score. Equal weighting is transparent and defensible to non-technical government stakeholders, and doesn't require a validated statistical or participatory weighting exercise before the indicator set itself has been confirmed against real data.

**Revisit when**: real data is available and the OECD Handbook's Step 4/6 correlation and double-counting checks can be run — if indicators within a dimension turn out to be highly collinear, equal weighting may need to be reconsidered for that dimension specifically.
