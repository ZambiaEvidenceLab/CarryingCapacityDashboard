Methodology

Each Sector Index is a 0–100 score. Each Indicator is winsorised (1st/99th percentile) then min-max normalised across all 116 districts, so scores are relative to the cohort, not a fixed benchmark.

Indicators average within a Dimension (Supply / Access); Dimensions average within a Sector. Environment has no Dimensions — its Indicators average directly.

Why isn't the national average 50? Min-max only pins the lowest district to 0 and the highest to 100 — the mean sits wherever the distribution's mass is. Averaging several 0–100 Indicators into a Sector Index also pulls the spread toward the middle.

Darker = more capacity. The five Sector Indices are never combined into a single composite score.
